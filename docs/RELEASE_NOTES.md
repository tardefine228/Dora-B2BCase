## Исправлено

1. **Очистка ввода:** единая бережная нормализация одиночного и пакетного ввода. Убираются нумерация, служебные префиксы и невидимые символы; сохраняются бренд, модель, характеристики, «не» и «без». Исходное название остаётся в ответе.
2. **Коды и исключения:** полный код с тремя цифрами в последнем сегменте теперь принимается и классификатором, и загрузкой каталога. Исключения и позиции без кода не индексируются как положительные. Область действия исключения ограничена позицией. Выдача старого Qdrant-индекса сверяется с текущими строками каталога.
3. **Готовность модели:** Dockerfile сам обучает лёгкий реранкер; веса не скрываются пустым bind-mount. Файлы модели включены в архив для локального запуска. Контрольная сумма каталога хранится в модели; устаревшие веса и эвристический fallback не выдаются за калиброванную вероятность. Добавлены диагностика readiness и защищённое перечитывание весов.
4. **Источники:** HTML-просмотр с подсветкой названия, страницами и явным обозначением распознанного текста. Сохранён JSON API. При отсутствии страницы больше не показывается начало документа. Текст экранируется, опасная схема ссылки отклоняется, старый фрагмент не кэшируется браузером. Есть ссылка на первоначальную официальную публикацию; актуальность редакции она не подтверждает.
5. **Обновление базы:** ZIP связывает каталог и текст контрольными суммами. Проверяются состав архива, размер и наличие указанных страниц. CSV/JSON без текста отключает прежний источник. Перечень обновляется без пересборки приложения; модель можно переобучить и перечитать отдельно. Для Qdrant нужна переиндексация.
6. **Импорт и интерфейс:** распознаются полные заголовки, есть текстовый автовыбор столбца, выбор листа и ручная настройка. Первый товар без заголовка не теряется. Предпросмотр поясняет пропуск пустых ячеек и сохранение повторов. Список свыше 100 товаров отклоняется без тихой обрезки. Показаны альтернативы; сбой опроса завершает состояние загрузки. Excel-библиотека вынесена в отложенную загрузку.
7. **Проверки и документация:** устранены ошибки Ruff, добавлены проверки регрессий импорта, очистки, источников, обновлений и исключений. Исправлен подсчёт Top-3: основной ответ плюс только две альтернативы. Обновлены README, API-контракт и регламент обновления.
