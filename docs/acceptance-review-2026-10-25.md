## Как измерить скорость на своей машине

Запустить Docker Desktop и приложение. Подготовить UTF-8 CSV с минимум 100 разными реальными названиями в колонке query; необязательная expected_code содержит проверенный код. Запуск из корня:

```powershell
python scripts/check_acceptance.py goods.csv --output acceptance-report.json
```

Скрипт создаёт обычную задачу и записи журнала. Сначала измеряет пакет, затем 20 одиночных запросов. Итог pass относится к времени, полноте и формату ответов, а не к юридической точности. Число совпадений с заданными expected_code выводится отдельно. Пустой expected_code не считается разметкой отсутствия в перечне. Ошибка HTTP/сети завершает команду ненулевым кодом.

Для холодного измерения перед запуском нужно перезапустить API и worker и дождаться readiness. Повторный прогон на тех же названиях может пользоваться кэшем; не выдавайте его за холодный. Зафиксируйте CPU/RAM и идентификатор образа рядом с отчётом. Финальное подтверждение требований возможно только после проверки на целевом образе и эталонной разметке.
