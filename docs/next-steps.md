## 3. Отдельный PR: train/serve-расхождение `retrieval_score` (меняет статусы)

Сейчас `CatalogClassifier._rank_to_response` передаёт реранкеру
`retrieval_score=0.0` для всех кандидатов, поэтому признак `retrieval_margin`
(вес 1.268 в модели уверенности) в проде всегда 0 — часть занижения сырой шкалы
объясняется этим. В C1 это сознательно не трогали: исправление меняет статусы
(`ok` 33 → 55 из 214), а ТЗ требовало неизменности статусов.

План:

1. Передавать в `RankedCandidate` реальный лексический скор из `_retrieve`
   (значение уже посчитано — сейчас выбрасывается).
2. Пересобрать модель `python scripts/build_model.py` — пороги `ok`/`review`
   пересчитываются на валидационных группах автоматически (там признак был
   ненулевым и в обучении, и в калибровке).
3. Переснять `eval/run_eval.py --sweep`, сравнить с текущими метриками
   (83.7 / 89.2 / 93.8 / 100, ECE 0.038). Ожидание: сырая ECE падает
   ≈0.355 → 0.30, статусов `ok` больше; калибровка пересобирается и станет ближе
   к единичной.
4. Обновить `eval/experiments.md` (новый эксперимент), при необходимости —
   CI-гейты и `REVIEW_CONFIDENCE_FLOOR`.
5. Тест-дрейф (`test_calibration_platform_mirrors_the_api_confidence`) должен
   остаться зелёным: он сверяет воспроизведение пайплайна с живым классификатором,
   то есть поймает рассинхрон копии и API.

## 4. Гигиена и грабли (чтобы не наступать повторно)

- **Артефакты модели не коммитятся** (`models/*` в `.gitignore`). После свежего
  клона/пересоздания песочницы: `python3 scripts/build_model.py` (~6 минут;
  детерминировано, seed 1875). Без артефакта ML-тесты скипаются — это штатно:
  CI test-job собирает без модели, а `quality`-job собирает её сам.
- **`eval/eval_report.md` всегда переснимать с `--sweep`** — без флага таблица
  свипа исчезает из отчёта (файл диффится лишний раз).
- **Любое изменение порога/признаков** = пересборка модели + `--sweep` +
  `eval/experiments.md` + проверка CI-порогов в `.github/workflows/lint.yml`.
- **Не использовать `eval/labeled_examples.csv`** ни для обучения, ни для
  калибровки — это измерительный набор (проверяется тестом
  `test_calibration_platform_does_not_reuse_labeled_queries`).
