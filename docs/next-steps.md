## 4. Гигиена и грабли (чтобы не наступать повторно)

- **Артефакты модели не коммитятся** (`models/*` в `.gitignore`). После свежего
  клона/пересоздания песочницы: `python3 scripts/build_model.py` (~6 минут;
  детерминировано, seed 1875). Без артефакта ML-тесты скипаются — это штатно:
  CI test-job собирает без модели, а `quality`-job собирает её сам.
- **`eval/eval_report.md` всегда переснимать с `--sweep`** — без флага таблица
  свипа исчезает из отчёта (файл диффится лишний раз).
- **Любое изменение порога/признаков** = пересборка модели + `--sweep` +
  `eval/experiments.md` + проверка CI-порогов в `.github/workflows/lint.yml`.
- **Не использовать `eval/labeled_examples.csv`** ни для обучения, ни для
  калибровки — это измерительный набор (проверяется тестом
  `test_calibration_platform_does_not_reuse_labeled_queries`).
