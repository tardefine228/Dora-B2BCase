# Расшифровки неоднозначных кодов

Источник: https://classifikators.ru/assets/downloads/okpd/okpd.xlsx
Скачан 13.11.2026. Метаданные и SHA-256 исходного файла сохранены в
`api/app/reference/okpd2.json`. Заголовок самого XLSX указывает изменение
149/2026, хотя веб-страница справочника сообщает 151/2026: записана редакция
именно скачанного файла, без заявления о полной актуальности. Официальный
сайт Росстата при проверке был недоступен из-за ошибки сертификата.
Это вспомогательный справочник наименований, не новая редакция ПП1875.

21 186 расшифровок загружаются на сервере один раз. API добавляет
`okpd2_title` и `okpd2_source` к каждому варианту уточнения; поля необязательные,
старые результаты остаются читаемыми. В браузер отправляются только нужные
названия, а не весь справочник. Новые коды из обновлённого каталога тоже
получают описание, если они присутствуют в справочнике.

В текущем каталоге 87 групп с несколькими кодами; покрыты 117 из 119 кодов
этих групп. Не найдены 22.22.14.000 и 32.50.23.000: автоматической подмены
родительским кодом нет. Для них показана просьба сверить документацию.

Интерфейс выделяет буквальные различия между названиями и показывает
иерархию (включая категорию 10.51.30.100 и подкатегорию 10.51.30.110).
Для одинаковых названий дополнительно показана ближайшая отличающаяся
родительская группа из справочника (например, струнные и духовые альты).
Подсказки не выбирают код, не повышают уверенность и не меняют поиск.
Отсутствие различающихся слов не означает взаимозаменяемость кодов.
Выбор подтверждается пользователем; отказ от выбора оставляет исходный
статус needs_clarification. Название позиции постановления сохранено отдельно.

Обновление вспомогательного справочника:
`python scripts/import_okpd_reference.py path/to/okpd.xlsx`, затем обычная сборка.
Это независимо от существующего обновления каталога ПП1875 без передеплоя.

Проверки: frontend unit/build, браузерные сценарии (включая масло и шприцы),
api/tests/test_okpd_reference.py и api/tests/test_ambiguity.py.

Проверка применённой Docker-сборки 13.11.2026:
- 52 frontend unit-теста, 17 браузерных сценариев и 61 тест API прошли.
- API healthy; API и worker пересозданы из нового образа, данные сохранены.
- Реальные запросы: масло сливочное — 2,639 с; шприц — 2,215 с;
  альты — 2,170 с; фильтр — 2,209 с; микроскоп — 2,209 с.
  Во всех пяти ответах получены расшифровки и контекст групп.
  Это проверка сценариев уточнения, не измерение точности классификации.
- Загрузка E5 из сети оборвалась. При сборке использованы сохранённые веса
  intfloat/multilingual-e5-small из предыдущего образа; основной Dockerfile
  не менялся. Штатное обучение и проверка моделей завершены полностью.
  Проверка не приняла векторный ранжировщик: он не улучшил метрики.
  Остались E5 для поиска и лексический ранжировщик.
