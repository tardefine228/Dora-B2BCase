# Артефакты модели

Здесь лежит всё, что сервис загружает в рантайме. Файлы входят в образ (`api/Dockerfile`),
поэтому их не пересобирают при старте — но и не правят руками: у каждого файла ниже есть
команда-производитель и sha256, а `api/tests/test_shipped_artifacts.py` сверяет их с этим
списком. Если тест упал после пересборки — обновите sha256 в таблице тем же коммитом.

## Происхождение и воспроизводимость

* Каталог: 984 позиции, `data/data.csv`. Размеченный набор: 274 строки
  (`eval/labeled_examples.csv`), из них 201 с ожидаемым кодом, 32 проверенных «вне перечня»
  и 41 спорная (`label_kind`, см. `docs/labeling-doctrine.md`).
* `reranker.json` **воспроизводится байт в байт**: две независимые полные сборки дают один и тот
  же sha256. Это и проверяет CI-шаг «Shipped artifacts match a rebuild».
* `reranker.tfidf.json` **не воспроизводится побайтово**: два прогона дают 40226 и соседние
  значения числа обучающих пар, потому что шортлист кандидатов зависит от порядка сложений в
  BLAS. Метрики на размеченном наборе при этом совпадают построчно, поэтому `dense-gate.json`
  хранит sha256 проверенного файла, а допуск сравнивает метрики, а не хеши.
* `tfidf_embedder.json` различается между сборками только полем `trained_at`; частоты документов
  совпадают — это проверяет
  `test_shipped_tfidf_embedder_is_fitted_on_the_current_catalog`.
* `dense-gate.json` — отчёт прогона допуска от 2026-10-24; его `baseline.sha256`
  (`9395a262…`) — это `reranker.json` **той** сборки: база переобучается тем же кодом в том же
  прогоне, поэтому отчёт доказуемо относится к своей паре файлов. Отгруженный `reranker.json`
  пересобран 2026-10-25 (эксп. 34, порог `ok` 0.77 → 0.80), поэтому его sha256 в таблице выше
  другой; отчёт при этом не переписывается — это запись о допуске векторного артефакта, а не
  описание текущей лексики. Тест сверяет, что `baseline` отчёта — лексический артефакт того же
  тренера, а не «файл сегодня» (`test_gate_report_baseline_is_the_lexical_artifact_of_its_run`).
  С 2026-10-24 отчёт пишется по пулу прогонов
  (`runs: 4`, `seeds: [1875, 1876, 1877, 1878]`, `decision_basis: pooled`): один прогон — это
  одно разбиение обучающих данных, и на нём вердикт по тишине менялся от сида к сиду.

## Измерено на текущих артефактах

Каталоговый режим, эмбеддер `tfidf`, 274 строки размеченного набора
(`EMBEDDER_BACKEND=tfidf eval/run_eval.py`):

| Конфигурация | top-1 (с кодом) | top-3 | верный `not_found` | top-1 по всем | ECE |

| `VECTOR_SEARCH=false` → `reranker.json` | 94.5 % | 98.5 % | 96.9 % | 94.8 % | 0.026 |
| `VECTOR_SEARCH=true` → `reranker.tfidf.json` (замер 2026-10-24) | **95.5 %** | **99.0 %** | **96.9 %** | **95.7 %** | 0.029 |

Лексическая строка — замер отгруженного файла 2026-10-25: волна 5 лексикона и правило слабой
подсказки (top-3 97.5 → 98.5 %, тишина без изменений), порог `ok` 0.80 вместо 0.77, из-за чего
уверенность стала осторожнее (ECE 0.018 → 0.026 при цели 0.15). Векторная строка — замер
2026-10-24, до волны 5: файл `reranker.tfidf.json` в этом прогоне не переобучался, поэтому его
числа относятся к предыдущей лексике и к порогу 0.77; по пулу четырёх прогонов допуска он даёт
+7 top-1 / +14 top-3 / +4 верной тишины (`--gate-seeds`, `eval/experiments.md`, эксп. 29).
Разница ECE внутри разброса по сидам (0.013…0.045).

## Какой артефакт реально скорит

| Ситуация | Артефакт |
| --- | --- |
| `VECTOR_SEARCH=true`, эмбеддер `tfidf` | `reranker.tfidf.json` |
| `VECTOR_SEARCH=false` | `reranker.json` |
| `SEMANTIC_RERANKER=lexical` (при включённых векторах) | `reranker.json`, векторы остаются только кандидатами — откат без пересборки образа |
| эмбеддер без своего артефакта (например e5 в образе) | `reranker.json` + предупреждение в лог |

Фактический выбор виден в `GET /health/ready` → `vector_search.reranker` и `vector_search.scoring`.

## Пересборка

```bash
python scripts/build_model.py --models-dir models                     # лексика + эмбеддер
python scripts/build_model.py --dense --gate --models-dir models      # + векторный, с допуском
cp models/reranker.json models/reranker.tfidf.json models/dense-gate.json ml/artifacts/
```

`--gate` переобучает лексическую базу тем же кодом (≈ 3 мин) и удаляет векторный артефакт, если
тот не прошёл допуск. После пересборки обновите sha256 в таблице выше — иначе упадёт
`api/tests/test_shipped_artifacts.py`.
