# Dora B2B — демо-интерфейс классификатора

React + TypeScript + Vite. Страница отвечает API v1.0 (`docs/api-contract.md`): одиночный товар, пакетная обработка файла (.xlsx/CSV до 100 строк), прогресс, сортировка и выгрузка Excel.

## Запуск в Docker (основной путь)

Из корня репозитория: `docker compose up --build`. Сборка идёт в `api/Dockerfile`, этап `ui-build` (`npm ci` + `npm run build`), в образ попадает только `dist/`. Страница: http://localhost:8000/ui/. Проверка: `bash scripts/docker_smoke.sh --build`.

## Разработка

Нужен Node.js 22 или новее.

```bash
# терминал 1, из корня репозитория
PYTHONPATH=api uvicorn app.main:app --port 8000 --no-proxy-headers

# терминал 2
cd frontend
npm ci
npm run dev        # откройте адрес на /ui/, который напечатает Vite
```

`/classify` и `/source` проксируются на `API_PROXY_TARGET` (по умолчанию `http://127.0.0.1:8000`). Для другого адреса API: `API_PROXY_TARGET=http://host:port npm run dev`.

Без запущенного API страница покажет ошибку «Нет связи с сервером классификации».

## Проверка

- «Электрочайники»: код 27.51.24.110, статус «Уверенный результат», ссылка «Открыть пункт постановления».
- «Ноутбук Lenovo IdeaPad»: код 26.20.11 (портативные компьютеры), статус «Требует проверки».
- «Холодильник бытовой»: статус «Не найдено», без ссылки (товара нет в перечне).
- Загрузите `examples/products.csv`, выберите столбец «Название товара», нажмите «Обработать список»: появятся прогресс, таблица, сортировка и «Скачать Excel» (`classification-results.xlsx`).
- Пустое название, файл больше 5 МБ или больше 100 строк, неподдерживаемое расширение, пустая ячейка в выбранном столбце: понятная ошибка.
- `npm run build` проверяет TypeScript и создаёт `dist/`.

## Формат входа

.xlsx или CSV в UTF-8, до 5 МБ; первая строка — заголовки, далее 1–100 непустых строк. Для Excel берётся первый лист. Старый .xls сохраните как .xlsx. Максимальная длина названия — 500 символов.

## Где что лежит

- `src/api.ts` — клиент API: `POST /classify`, `POST /classify/batch`, опрос `GET /classify/batch/{job_id}` каждые 500 мс (до 3 минут). Ответы snake_case переводятся в `Result`. `not_found` приходит с `confidence = null`. Ошибки API и сети выводятся текстом.
- `src/App.tsx` — страница и состояния.
- `src/files.ts` — чтение файлов и выгрузка Excel.
- `src/styles.css` — оформление (не менять без согласования).
- `vite.config.ts` — `base: '/ui/'`, прокси и `allowedHosts` для превью.

Файлы обрабатываются в браузере и не отправляются на сервер, кроме названий товаров для классификации. Ссылки на пункт постановления ведут на `/source/{record_id}` (фрагмент `data/source_text.txt`). Подбор кода — подсказка, результат требует проверки специалистом.
