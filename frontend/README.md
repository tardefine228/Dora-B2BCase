# Dora B2BCase — React-интерфейс

Сайт доступен в Docker по **http://localhost:8000/ui/**. Запуск и диагностика Windows:
[`../docs/START_WINDOWS_DOCKER.md`](../docs/START_WINDOWS_DOCKER.md).

## Что делает интерфейс

- Поиск одного товара через `POST /classify`, статусы, уверенность, альтернативы и ссылки на пункты.
- Оценка результата **«верно / неверно с правильным кодом / нет в перечне»** через `POST /feedback` (теперь добавлен в API; оценки хранятся на сервере).
- Загрузка до 100 товаров: файлы Excel/CSV/PDF/DOCX/JSON/TXT передаются в `POST /classify/file`; выбор столбца определяет **сервер**, клиент показывает сведения о парсинге.
- Прогресс через SSE `/classify/batch/{id}/events`, запасной polling. При открытии страницы
  идущая обработка возобновляется, а завершённый текущий отчёт заново загружается с сервера
  по opaque `job_id`; локальный снимок товаров для этого не используется.
- Результаты текущей проверки возвращаются при возврате на страницу по «Назад»
  (ушли в пункт перечня и вернулись), а также при восстановлении серверного задания.
- Внизу страницы — история последних трёх файлов (`src/history.ts`). В браузере хранятся
  только имя файла, `job_id`, время и статус; названия товаров и строки результатов не
  сохраняются. Любой доступный отчёт из списка можно снова открыть, пока не истёк срок
  его хранения на сервере.
- Одинаковые официальные названия объединяются в уточнении в одну карточку; коды и их
  позиции перечня показываются внутри. Равные коды с разными юридическими описаниями
  остаются отдельными, а страница источника сохраняет обычный вид постановления.
- Колонка `№` в результатах списка — простой счётчик строк 1…N текущего порядка. Тот же счётчик
  едет в выгрузки: первая колонка Excel и последняя (`row`) в CSV.
- Excel и CSV экспорт результатов (в том числе оценки пользователя текущей сессии), ExcelJS загружается только при экспорте.

## Для разработчика

Нужен Node.js 22.18 или новее.

```bash
# терминал 1, из корня репозитория
PYTHONPATH=api uvicorn app.main:app --port 8000 --no-proxy-headers

# терминал 2
cd frontend
npm ci
npm run dev
```

В отдельном терминале или Docker должен работать API на `http://127.0.0.1:8000`.
Сборка: `npm run build`. Сборка фронтенда входит в `api/Dockerfile`.
Проверки API-клиента, отмены задач, хранилища и CSV-экспорта: `npm test`.

Код: `src/api.ts` — API и SSE; `src/App.tsx` — компоненты и состояние;
`src/files.ts` — экспорт; `src/styles.css` — оформление.

`frontend/examples/products.csv` — тестовый список. Для PDF/DOCX/JSON
используйте собственные файлы без конфиденциальных данных.

**Ограничения:** обработка файлов полностью серверная (для Excel/CSV выбрать колонку
вручную нельзя). Общей серверной истории и авторизации пользователей нет: список трёх
файлов локален для текущего браузера, а доступность результатов ограничена сроком
хранения задания. Для долгого хранения используйте «Скачать Excel» / «Скачать CSV».
