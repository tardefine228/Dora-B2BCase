# Интерфейс Dora B2BCase

React + TypeScript + Vite. Одиночный поиск, CSV/XLSX до 100 товаров, прогресс, сортировка, экспорт Excel, альтернативы и читаемый источник.

## Запуск

Основной путь из корня: `docker compose up --build`, затем http://localhost:8000/ui/ .

Для разработки запустите API: `python -m uvicorn app.main:app --app-dir api --port 8000`.
В другом терминале: `cd frontend`, `npm ci`, `npm run dev`.
Vite проксирует API на `API_PROXY_TARGET` (по умолчанию http://127.0.0.1:8000).

Нужен Node.js 22.18+. `npm run build` проверяет TypeScript и собирает `dist`; `npm test` проверяет импорт таблиц.

## Импорт

CSV UTF-8 / Windows-1251 или XLSX, до 5 МБ. Старый XLS нужно пересохранить. Максимум 100 непустых названий по 500 символов; превышение отклоняется без обрезания списка.

Столбец определяется по распространённым заголовкам или текстовым значениям. Перед отправкой показаны количество строк и три примера. В настройках можно выбрать другой лист/столбец и включить или убрать заголовок. Первая товарная строка файла без заголовка сохраняется, дубликаты сохраняются, пустые ячейки пропускаются.

Файл читается в браузере; серверу отправляются выбранные названия. Excel-библиотека загружается только при чтении XLSX или экспорте.

## Результаты

`confidence_kind` различает уверенность обученной модели, точное совпадение кода и некалиброванный скоринг. Для слабого совпадения предлагается проверка; при отсутствии результата показывается прочерк. Альтернативы имеют собственные ссылки на позиции.

Ссылка открывает HTML-фрагмент по `/source/{id}?format=html`. JSON-версия остаётся доступной без параметра. При сбое сети или опроса пакетная обработка перестаёт отображаться как бесконечно активная.

## Дополнительная проверка браузером

Необязательный сценарий `tests/ui-smoke.cjs` требует отдельно установленного Playwright и Chromium. После `npm install --no-save playwright` и `npx playwright install chromium` запустите `node tests/ui-smoke.cjs` на работающем API. `BASE_URL` задаёт адрес, `SCREENSHOT_DIR` — каталог снимков. В текущей среде Chromium не удалось скачать, поэтому успешная сборка не выдаётся за выполненную визуальную проверку.
