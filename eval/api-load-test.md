**Дата:** 2026-10-07 (UTC)  
**Режим:** локальный FastAPI `catalog`, Python 3.11.2, Linux sandbox; запуск не через Docker.  
**Каталог:** 1 126 записей из `data/data.csv`; ML-модель и Qdrant в этом прогоне не использовались.

## Команда

```bash
PYTHONPATH=api python scripts/load_test.py \
  --base-url http://127.0.0.1:8000 \
  --concurrency 10 \
  --items 100 \
  --pid <PID_UVICORN>
```
